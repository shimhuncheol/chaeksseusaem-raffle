# 책쓰샘 행운 추첨

경기교육연구 페스타 2026 · 경기독서교육연구회(책쓰샘) 부스에서 쓰는 구슬 추첨 웹앱입니다.

- **구슬 떨어뜨리기**: 버튼(또는 스페이스바)을 누르면 금빛 구슬이 장애물 핀을 튕기며 내려와 아래의 '도서' 또는 '간식' 칸에 도착합니다.
- **확률**: 결과는 설정한 당첨 확률(기본 도서 10%)로 먼저 정해지고, 구슬은 실제 물리 계산으로 그 칸에 자연스럽게 떨어집니다. 도서가 다 떨어지면 간식만 나옵니다.
- **무제한 상품**: 간식처럼 끝없이 줄 수 있는 상품은 무제한으로 둘 수 있습니다.
- **효과**: 핀이 반짝이고 소리가 나며, 마지막 순간은 슬로모션입니다. 당첨되면 햇살무늬, 폭죽, 금화와 축하 화면이 나오고, 확률이 낮은 상품은 '대박!' 연출이 더 크게 나옵니다.
- **수정**: '상품·화면 수정' 버튼에서 상품 이름·칸 글자·수량·색, 당첨 확률, 장애물 줄 수, 제목·부제, 추첨 기록을 바꿀 수 있습니다. 설정과 기록은 사용하는 브라우저에 저장됩니다.
