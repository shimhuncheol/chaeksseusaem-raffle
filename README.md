# 책쓰샘 행운 추첨

경기교육연구 페스타 2026 · 경기독서교육연구회(책쓰샘) 부스에서 쓰는 상품 추첨 웹앱입니다.

- **한 명씩 뽑기**: 룰렛을 돌리면 남은 수량에 비례한 확률로 상품이 나옵니다. 다 나간 상품은 룰렛에서 빠집니다.
- **명단에서 당첨자 뽑기**: 참가자 명단을 넣고 상품을 고르면 원고지 칸에 당첨자 이름이 써집니다. 한 번 뽑힌 사람은 다시 뽑히지 않습니다.
- 상품 이름·수량·색, 화면 제목·부제는 화면 아래 설정에서 바꿀 수 있고, 설정과 기록은 사용하는 브라우저에 저장됩니다.
