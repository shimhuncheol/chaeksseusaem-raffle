# 책쓰샘 행운 추첨

경기교육연구 페스타 2026 · 경기독서교육연구회(책쓰샘) 부스에서 쓰는 상품 추첨 웹앱입니다.

- **룰렛 뽑기**: 잘게 나뉜(24~80칸) 카지노풍 룰렛을 돌리면 남은 수량에 비례한 확률로 상품이 나옵니다. 다 나간 상품은 룰렛에서 빠지고, 간식처럼 무제한인 상품은 '확률 비중'으로 계산합니다.
- **명단에서 당첨자 뽑기**: 참가자 명단을 넣고 상품을 고르면 당첨자 이름이 굴러가다 멈춥니다. 한 번 뽑힌 사람은 다시 뽑히지 않습니다.
- 당첨되면 금빛 후광, 폭죽, 금화, 축하 화면이 나옵니다.
- 상품 이름·칸 글자·수량·무제한·색, 룰렛 칸 수, 화면 제목·부제는 '상품·화면 수정' 버튼에서 바꿀 수 있고, 설정과 기록은 사용하는 브라우저에 저장됩니다.

만든 사람: 심훈철
